# conductor graph output format

The `conductor graph` command emits Mermaid `flowchart TD` diagrams with this exact structure:

- `flowchart TD` header line
- `%% Generated by conductor graph` comment
- `%% Workflow: <name>` comment
- `%% Depth: <remaining>` comment (remaining recursion depth at this render level)
- `classDef` block for node styling
- Nodes sorted alphabetically by name
- Subgraphs for parallel/for-each/workflow groups (sorted by name)
- Edges sorted lexicographically
- Class assignments sorted
- Entry-point node highlight applied last (bold border)
- Trailing newline

Edge styles:
- Conditional routes use labeled edges: `-->|"condition"|`
- Loop-back routes use dotted edges: `-.->`

Node shapes by type:
- agent: rounded rectangle (default)
- script: stadium shape
- set: hexagon
- wait: circle
- human_gate: diamond
- terminate (success): double-circle
- terminate (failed): double-circle (different class)
- workflow: subgraph
- $end: circle
