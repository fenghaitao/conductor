`_conductor_run_dir()` returns the current working directory's `tmp/` by default (not `$TMPDIR/conductor/`). The `CONDUCTOR_TMPDIR` environment variable overrides both the run directory for event logs and the checkpoint directory. When testing, you must monkeypatch `_conductor_run_dir` — simply setting `CONDUCTOR_TMPDIR` in the test runner's environment may collide with real data.
